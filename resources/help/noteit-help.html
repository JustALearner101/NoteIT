📐 1. Hierarki Workspace, Multi-Tab & Split-Pane

NoteIT menggunakan struktur tiga lapis yang dirancang untuk dokumentasi rekayasa perangkat lunak dan arsip pengetahuan:

1. Notebook (Level Atas)

Wadah proyek utama (mis. Core Platform, Semantic CMS). Pilih dari dropdown di bagian atas Index Rail Sidebar.

2. Section (Penanda Warna)

Kelompok spesifikasi dengan 3px Drafting Marker Strip (Cobalt, Amber, Teal, Red, Violet, Slate).

3. Page & Sub-page

Setiap halaman memiliki kode unik (mis. ARC-01) dan dapat memiliki sub-halaman bersarang.

4. Split-Pane berdampingan

Tahan Alt + Klik halaman di sidebar (atau klik ikon SPLIT) untuk membuka dua spesifikasi sekaligus.

🔀 2. Mode Ganda: Block Document vs Spatial Canvas

Setiap halaman di NoteIT dapat dialihkan kapan saja antara Block Document dan Spatial Canvas menggunakan tombol di Spec Header atau shortcut Ctrl + Shift + M.

  • Block Document Mode: Editor terstruktur untuk menulis spesifikasi teknis, blok kode, tabel database/Gantt, diagram Mermaid/DOT, skema DBML, lampiran PDF, dan [[WikiLinks]].
  • Spatial Canvas Mode: Papan kanvas 2D tak terbatas dengan grid 24px presisi tempat seluruh blok halaman muncul sebagai kartu spasial yang bisa dihubungkan dan ditata bebas.

🗄️ 3. Referensi Sintaks DBML (Database Markup Language)

Blok DBML Schema mem-parsing skema tabel secara instan menjadi diagram relasi (ERD) interaktif dan generator DDL SQL. 

Table users {
  id uuid [pk]
  email varchar [unique, not null]
  role varchar
  created_at timestamp
}

Table projects {
  id uuid [pk]
  owner_id uuid [not null, ref: > users.id]
  name varchar [not null]
  status varchar
}

Ref: projects.owner_id > users.id
  • Gunakan atribut [pk] untuk Primary Key, [not null], dan [unique].
  • Relasi dapat ditulis langsung di dalam kolom [ref: > tabel.kolom] atau sebagai baris terpisah Ref: tabelA.kolom > tabelB.kolom.

📊 4. Diagram Mermaid & Graphviz DOT

NoteIT merender diagram teknis secara 100% lokal menggunakan mesin Mermaid dan WebAssembly Graphviz (@viz-js/viz).

Contoh Mermaid

flowchart LR
  Client[Desktop Renderer] -->|IPC Invoke| Main[Electron Main]
  Main -->|WAL Mode| DB[(SQLite FTS5)]

Contoh Graphviz DOT

digraph Architecture {
  rankdir=LR;
  node [shape=box, style=rounded];
   Gateway -> AuthService -> Postgres;
}

📅 5. Gantt Roadmap & Project Database Block

Tambahkan blok Project Database / Gantt untuk melacak milestone teknis, pemilik tugas, progres persen, dan visualisasi grafik (Gantt, Bar, Line, Pie) secara langsung di dalam dokumen spesifikasi.

✨ 6. AI Chat Workbench (Free Chat)

Akses halaman AI Chat melalui tombol di footer sidebar kiri atau shortcut Ctrl + Shift + C:

  • @Mention Halaman: Ketik @ atau klik tombol + di kotak input untuk melampirkan halaman NoteIT aktif sebagai konteks percakapan.
  • Mode Asisten: Pilih antara Free chat, Spec Architect, DBML Schema Co-Pilot, atau Diagram Generator.
  • Kirim ke Dokumen: Hasil respons AI (termasuk draf spesifikasi atau blok kode DBML/Mermaid) dapat langsung disisipkan ke halaman aktif atau dibuat menjadi halaman spesifikasi baru dengan sekali klik.

🎨 7. Theme Presets & Custom Theme Studio

Buka Settings (⚙️) → Appearance untuk memilih dari 8+ preset tema kurasi atau merancang tema kustom Anda sendiri:

  • Graphite Slate & Archival Vellum: Tema gelap & terang standar NoteIT.
  • Orca Carbon: Matte carbon gelap minimalis dengan kontras tenang dan aksen hangat.
  • Code.Zone Amber: Latar belakang True OLED Black dengan aksen oranye-amber khas terminal developer.
  • Finns Cosmic Nebula: Atmosfer indigo-violet dengan Ambient Aurora Backdrop Glow.
  • Custom Theme Studio: Atur warna Canvas, Chrome, Elevated Card, Border, Teks, dan Aksen secara bebas, simpan ke daftar tema, atau ekspor/impor sebagai JSON.

⚙️ 8. Navigasi Settings ala Orca

Klik ikon roda gigi ⚙️ di bagian bawah sidebar (atau tekan Ctrl + ,) untuk membuka tampilan penuh Settings. Gunakan kolom Search settings (Ctrl + F) di kiri atas untuk menyaring pengaturan apa pun secara instan, dan klik ← Back to app (atau Esc) untuk kembali ke editor.

🛡️ 10. Penyimpanan SQLite WAL & Backup Otomatis

Seluruh catatan, diagram, dan lampiran disimpan secara lokal di komputer Anda:

  • SQLite WAL + FTS5: Menjamin penulisan cepat tanpa korupsi data dan pencarian teks penuh di bawah 5 milidetik.
  • Auto-Backup Berkala: NoteIT otomatis mencadangkan database (via VACUUM INTO) beserta asetnya setiap 10 menit dan saat aplikasi ditutup, menyimpan hingga 7 salinan terbaru.
  • Manual Backup & Markdown Export: Anda dapat memicu backup instan kapan saja melalui menu Settings → Storage & Backup.
